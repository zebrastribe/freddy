# Admin Guide

This guide explains how to use and manage the Freddy admin interface.

---

## Accessing the Admin Interface
- Open `admin.html` in your browser or navigate to `/admin/` if running locally.

## Features
- **View All Check-ins:** See a table of all user check-ins with timestamps, names, and coordinates.
- **Pagination:** Browse through check-ins page by page.
- **Map View:** See all check-ins plotted on a map.
- **Token Management:** (If enabled) View and manage access tokens.
- **Export Data:** (If available) Export check-in data for analysis.

## Usage
1. **Login:** If authentication is enabled, log in with your admin credentials.
2. **Browse Check-ins:** Use the table and pagination controls to view all check-ins.
3. **Map Interaction:** Use the map to visualize check-in locations.
4. **Export:** Use the export button (if present) to download data.

## Tips
- Use browser search (Ctrl+F) to quickly find a user or location.
- For troubleshooting, open browser DevTools (F12) and check the console for errors.

## Security
- Only authorized users should access the admin interface.
- Do not share admin credentials.
